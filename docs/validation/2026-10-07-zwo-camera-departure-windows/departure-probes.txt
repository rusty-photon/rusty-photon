# zwo-camera departure probes on Windows, 2026-10-07 (issue #1411)
#
# Client: walpaca.py / probes.py on the Fedora host. Every camera request runs
# inside the win11 guest (PowerShell Invoke-RestMethod against
# 127.0.0.1:11122) through the QEMU guest agent; the ms figure is the guest-side
# HTTP round trip. Times are host local time (UTC-7). The guest's clock, which
# stamps the service log in UTC, ran about 1.0 s behind the host's.
#
# Devices in this enumeration: 0 = ASI1600MM-Cool (USB3, the control),
# 1 = ASI178MM, 2 = ASI120MC-S (both on the PPBA's switched USB2 port).
#
# A departure is the PPBA `USB Hub` switch (PU) cut through ppba-driver on the
# host, then, as soon as the cameras are gone from the host's lsusb, a
# `virsh detach-device` of each one's hostdev, so the guest sees the surprise
# removal at once. The way back is the PU switch on, then a fresh
# `virsh attach-device` (a hostdev is pinned to the host device number it was
# attached with). `guest PnP` lines are Get-PnpDevice -PresentOnly in the guest.
